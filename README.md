# 直播中控台 LiveReview Console

> 面向直播电商团队的话术管理与复盘工具：把主播话术、客户问题、违规案例沉淀成结构化数据库，用 A/B 测试和数据看板驱动话术迭代，让复盘从"听回放"变成"看数据"。

## 背景

在 3C 数码品牌抖音官方旗舰店做运营时发现：直播复盘靠人工逐句听回放，单场 2 小时直播要花 1-2 小时；新主播缺少系统的话术支撑，上手周期长。本工具为此而建，并在团队内推广使用。

## 核心功能

- **话术库管理**：客户高频问题 → 标准回复脚本的结构化沉淀，支持分类、敏感问题标记、全局搜索
- **话术 A/B 测试**：同一问题的多个话术版本对照测试，用数据选出最优话术
- **转化场景库**：按场景组织话术组合，新主播直接调用
- **违规风控**：违规规则 + 违规案例库，导入话术自动做违规检查
- **复盘报表**：高频问题排行、分类占比趋势、主播排名统计、复盘记录，一键导出 Excel/Word 日报
- **批量导入**：CSV / Excel / Word / JSON 多格式导入（附模板），话术资产快速入库
- **多人协作**：Flask Web 架构，局域网内同事可直接访问，支持密码保护与移动端适配

## 处理流程

```
直播复盘/客户问题收集 → 批量导入（CSV/Excel/Word）
  → 话术库结构化（问题/脚本/场景/AB测试）
  → 数据分析（高频问题排行、趋势占比、排名）
  → 违规检查 → 复盘日报导出（Excel/Word）
```

## 技术栈

Python · Flask · SQLite · Pandas · OpenPyXL · python-docx · Waitress

话术脚本的生成与迭代结合 DeepSeek 等大模型辅助完成，工具侧负责结构化管理与数据验证。

## 快速开始

```bash
pip install -r requirements.txt
python app.py          # 本地访问 http://localhost:5000
```

局域网访问：`http://你的IP:5000`（可用环境变量 `LIVE_DB_PASSWORD` 设置访问密码）
